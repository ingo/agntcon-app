# Contributing

Issues and pull requests are welcome at https://github.com/ingo/agntcon-app.

* Open an issue first for anything larger than a typo or a small bug.
* Follow the formatting and patterns already in the code. Every user-facing string needs an English and a German entry.
* For UI changes, include a screenshot or a short screen recording.
* Run `./gradlew :core:jvmTest :app:shared:jvmTest` before you open a pull request.

By contributing you agree that your work is published under the [Apache License 2.0](LICENSE).
