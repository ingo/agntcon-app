# Contributing

Issues and pull requests are welcome.

* Open an issue first for anything larger than a typo or a small bug, so we can agree on the approach.
* Follow the formatting and patterns already in the code. Every user-facing string needs an English and a German entry.
* For UI changes, include a screenshot or a short screen recording in the pull request.
* Run `./gradlew :core:jvmTest :app:shared:jvmTest` before you open it.

By contributing you agree that your work is published under the [Apache License 2.0](LICENSE).
